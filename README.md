# Projet Collaboratif - React + Vite + Tailwind

## Installation

```bash
npm install
```

## Démarrage du serveur

```bash
npm run dev
```

## Backend (Express.js + PostgreSQL)

The backend code is located in the `backend/` folder. To get started:

1. Install dependencies:
   ```bash
   cd backend
   npm install
   ```
2. Set up your PostgreSQL database using the provided `schema.sql` file.
3. Configure your environment variables in a `.env` file (see `.env.example`).
4. Start the backend server:
   ```bash
   npm run dev
   ```
